## Scope and reuse
This library includes only public Yamaha/manufacturer/regulator reporting. It excludes private communications, relationship history, personal contact data, deal terms, confidential vessel figures and proposed joint work. Plans and historical evidence are labeled. Published capabilities do not establish technical fit, spare capacity, operator rights, permits or partner willingness. Yamaha Motor is distinct from Yamaha Corporation. Recheck time-sensitive sources before a later presentation.

The original research inventory also contained a negative-search note with two URLs in one field. That note is excluded here; it was never counted among the original 49 primary-source URLs.
