## Electricity tariff — PRIMARY verification
- SERA (regulator) Consumption Tariff: Commercial 1–6,000 kWh/mo = 22 halalah/kWh; **>6,000 kWh/mo = 32 halalah/kWh**; Governmental = 32; Industrial = 20 (all categories) — https://www.sera.gov.sa/en/consumer/electric-tariff/electric-tariff-categories/consumption-tariff [PRIMARY — sera.gov.sa geo-blocks the research sandbox; figures captured from the search index of the primary page and cross-confirmed on SEC's own page]
- SEC: "Commercial 1–6000 (kWh/Month) 22 (Halalah/kWh); More than 6000 (kWh/Month) 32" — https://www.se.com.sa/en/Ourservices/ColumnC/Bills-and-Consumption/ConsumptionTariffs/ [PRIMARY, same capture method]
- Corroboration: Saudi Gazette "current tariffs for the commercial sector is 22 … up to 6000 kWh per month and 32 halalas per kWh … exceeding 6000" — saudigazette.com.sa/article/652853 [SECONDARY]
- A fleet charging point will exceed 6,000 kWh/mo → **SAR 0.32/kWh = $0.0853/kWh** [PRIMARY-derived]. This is ~72% BELOW the $0.30/kWh canon default — use the sourced tariff per addendum rule ("use sourced local tariff if cheaper").
