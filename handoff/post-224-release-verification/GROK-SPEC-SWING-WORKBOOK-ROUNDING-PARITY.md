# Grok spec — Swing workbook rounding parity

## Decision

Patch the shared transparent-sheet generator. **Do not change Swing demand, fare, route IDs, aggregate JSON, growth case, or the canonical $10,453,754 floor.** The $3 display delta is generated by spreadsheet rounding semantics.

## Root cause

Four South Korea rows evaluate `5 × 274 × 0.65 = 890.5` revenue trips/year. The canonical Python model uses round-half-even (`890`); Excel/Google Sheets `ROUND` returns `891`. The workbook also computes raw market revenue as fractional vessels × **rounded** per-vessel revenue. That second rounding leaves a $2.738339747 rollup residue, displayed as $3.

Affected route IDs:

- `rn-79388bf546a1`
- `rn-b93989547df9`
- `rn-649a78c56f95`
- `rn-ba28d38bee02`

Observed effect:

- Four floored route rows: +$291 each in the workbook; +$1,164 total
- Raw SOM rollup: +$2.738339747; workbook displays $10,453,757 instead of canonical $10,453,754

## Generator patch

File: `finance/build_transparent_sheet.py`

1. Replace `ROUND` at model rounding boundaries with an explicit positive-number round-half-even expression matching Python. Cover selected trips/year and thin/mid/full scenario revenue/payback formulas.
2. Change `Market rev/yr raw` from `Vessels raw × ROUND(Revenue / boat / yr, 0)` to `Vessels raw × Revenue / boat / yr` (unrounded). This preserves fleet caps while avoiding a second rounding residue.
3. Search the sheet builder for other Python-versus-spreadsheet `.5` boundaries and include them in the parity test; do not silently change model semantics.

A compatible positive-number half-even pattern is:

```text
IF(MOD(x,1)=0.5, 2*ROUND(x/2,0), ROUND(x,0))
```

Use a helper in the generator rather than repeating ad hoc formula text.

## Blast radius and delivery

This is shared workbook logic. Run the model-to-sheet comparison for every partner and rebuild affected Google Sheets **in place**. Partner JSON and aggregates should remain byte-stable unless the audit reveals a separate defect.

Then regenerate Swing slides 8–10 from current sources, replace obsolete Sheet links on slides 8–11, and replay copy/visual gates.

## Acceptance

- Swing workbook `Market sizing!C15` = **$10,453,754**
- Swing transport-spend pool = **$104,537,675**
- Route-level trips/year, per-boat revenue, raw market revenue, and floored market revenue match `agg-swing.json` for all 39 modeled routes
- The four affected rows use 890 trips/year, not 891
- Model-to-workbook SOM delta = $0 before display rounding and after display rounding
- No economics-source changes
- All affected Sheets retain their existing IDs
- Swing remains release-held until stale slides and links are regenerated and reverified
