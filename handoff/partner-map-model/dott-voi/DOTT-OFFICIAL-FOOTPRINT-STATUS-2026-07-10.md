# Dott Official Footprint Status — 2026-07-10

## Executive verdict

- **Directory-confirmed current footprint:** **18 countries and 380 clean city/service-area rows** on Dott’s official current [Locations directory](https://ridedott.com/locations/). The page contains 381 raw entries; one, **Pápa**, is filed under Poland even though the place is in Hungary, so it is quarantined rather than silently reassigned.
- **Company aggregate:** Dott’s [Q1 2026 report](https://ridedott.com/press-release/q1-2026-financial-report/) says **400+ cities across 20 countries**. It does not name those countries and does not reconcile exactly with the 18-country public directory. This audit does not guess the two-country difference.
- **Brand status:** The company announced one Dott app/service/brand in October 2024 and said all former TIER cities would migrate by early 2025. Its May 2026 report says all vehicles are integrated into the Dott app. Current directory rows are therefore treated as Dott-branded service, while legacy TIER-only evidence is historical unless re-confirmed.
- **Lebanon:** **No — Dott is not demonstrably operating in Lebanon as of the audit date.** Lebanon is absent from the official current locations directory and from Dott’s explicit help-center country list; targeted searches found no official Dott or TIER launch/current-service evidence. This is a high-confidence **“do not count”** verdict, though it is based on absence of current evidence rather than an explicit Dott closure statement.

## Holds, contradictions, and explicit exclusions

### Explicit country exits

Dott’s [Q4 and FY 2025 Financial Report](https://ridedott.com/wp-content/uploads/2026/03/dott-q4-and-fy-2025-financial-report.pdf) explicitly says the company exited **Slovakia, Qatar, and Sweden during 2025**. These countries remain on some help/legal pages, but those retained pages are stale for current operating-status purposes. Sweden also has a conflicting 2025-story reference to a Gothenburg tender success; the later explicit exit disclosure controls, so Gothenburg is historical/conflicted, not current.

### Nordic countries

The current directory confirms **Denmark (14 rows), Finland (30), and Norway (4)**. **Sweden is not current**: Dott’s later FY2025 report explicitly says it exited Sweden during 2025, overriding retained legal/help pages and the conflicting Gothenburg tender-success narrative. No current official Dott city evidence was found for Iceland; it is not inferred into the footprint.

### United Kingdom / London

Dott’s own London tender/launch article is historical. London is absent from Dott’s current directory, and Transport for London’s current rental-trial page names only **Lime and Voi** as current providers. London is therefore an **explicit current exclusion** from the Dott footprint. Dott’s current UK directory rows are Basildon, Bath, Bristol, Brunel Uni, Chelmsford, Colchester, Glasgow, Milton Keynes, Nottingham, and South Gloucester.

### United Arab Emirates / Sharjah

Dott’s UAE terms, last updated **2025-09-23**, explicitly cover Dott-app rental service in **Dubai, Ras Al Khaimah, Sharjah, and Abu Dhabi**, while still naming the local contractual service/vehicles as TIER/Innohub. The current location directory lists Abu Dhabi, Dubai, and Ras Al Khaimah but omits Sharjah. Sharjah is retained as **official legal support / directory omission**, not counted in the 380 directory-confirmed rows pending in-app verification. This is consolidated/renamed service ambiguity, not evidence of a separate live TIER app.

### France, including northern France

The current directory supports 14 French service-area rows concentrated around Paris, Lyon, and Bordeaux. It names **no location in Hauts-de-France**. Targeted official searches found no current Dott evidence for Lille, Dunkirk, or Calais. Northern France is therefore **not currently supported by official city evidence**; this is an evidence absence, not an explicit exit statement.

### Source-data anomaly: Pápa

The current location directory places **Pápa** in the Poland section. Because Pápa is geographically in Hungary, the row is classified `source_cleanup_needed` with country `null`. It is not counted under Poland or silently reassigned to Hungary.

### Aggregate count mismatch

- Current public location directory: 18 named countries / 381 raw location labels (380 clean + 1 misfiled anomaly).
- May 2026 Q1 report: 20 countries / 400+ cities.
- Dott’s undated 2026 “Story of Our 2025” page and an earlier FY announcement: 21 countries / 400+ cities.
- March 2026 FY report: explicit 2025 exits from three countries.

These official materials appear to have different publication lags and counting bases. The structured inventory privileges the named current directory for city truth and retains aggregate statements only as unresolved context. No countries or cities are inferred to close the count gap.

## Evidence-tier/status rules used

- `city_supported` + `current_directory_listed`: exact label on Dott’s official location directory.
- `country_supported` + `current_aggregate_only`: official company aggregate without named-country detail; not enough to invent cities.
- `source_cleanup_needed`: stale/conflicted pages, malformed geography, legal-page/directory mismatch, or evidence absence.
- `explicit_exit_2025`: Dott’s own later financial-report exit disclosure.
- `historical_dott_not_current`: old Dott launch/tender evidence not corroborated today.
- `explicit_current_exclusion_by_authority`: current public-authority operator list excludes Dott.

## Source limitations

- The locations directory shows no publication or update date; “current” here means live content accessed on the audit date.
- Dott’s official aggregate country counts conflict with its named public directory and with explicit exit disclosures.
- Public legal/help pages can persist after an exit; they are not decisive without current directory/app corroboration.
- The app’s real-time map was not programmatically enumerated. Sharjah therefore remains a hold rather than a confirmed directory city.
- Absence from a public directory is not the same as an explicit closure. This distinction is preserved for Lebanon and northern France.
- No Atlas binding, routes, piers, economics, or inferred geography were created in this audit.
