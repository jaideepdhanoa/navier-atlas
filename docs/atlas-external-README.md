# Navier Atlas

Interactive global map of Navier's mobility opportunity landscape — cities, locales, POIs, and partner-scoped Stories.

**Live:** _(set after Vercel import)_

## What's inside

- `index.html` — single self-contained MapLibre GL atlas with all data inlined
- `vercel.json` — minimal static-hosting config
- Data: 41 cities · 307 locales · 427 POIs · 510 contacts · 50 canonical orgs

## Deploy

1. Import this repo in Vercel → framework preset **Other** → root directory `./`
2. No build command, no install command — pure static
3. Every push to `main` redeploys automatically

## Source

Generated from city files in the broader Navier knowledge base. Regeneration script: `build.py` (kept out of repo to minimize surface; ask Jaideep).
